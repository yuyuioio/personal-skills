# matlab_draw

使用用户已配置的 MATLAB 文件桥接执行绘图。把用户的自然语言要求转成可复现的 `.m` 脚本，自动提交任务、读取执行结果、检查输出并交付。默认不要求用户逐次复制脚本或手动导入数据。

## 已知本机配置

- MATLAB：R2026b，安装于 `Z:\MATLAB`。
- 固定桥接：`Z:\workspace\matlab-chatgpt-bridge`。
- MATLAB 正常启动时，`C:\Users\13204\Documents\MATLAB\startup.m` 自动加载桥接。用户仍需打开 MATLAB。
- 桥接自动启动和重启后的新任务执行均已在 2026-10-13 验证。新对话能否使用，必须实际检查目录权限和任务响应。
- 这些路径是这台电脑的配置，用户提供新路径或运行环境不同时，以实际配置为准。

## 执行绘图

1. 先读取固定目录的 `status.json` 和桥接代码，确认协议仍兼容。使用本技能的 `scripts/bridge_job.py status` 可获取状态及状态文件年龄。`ready` 且持续更新时可提交；`busy` 表示可能正在执行其他任务。不要仅凭旧的 `ready` 文件判断桥接在线，长任务也可能暂停状态更新时间。
2. 使用当前对话附件、当前工作区数据或用户明确指定的本地数据。先检查工作表、列名、单位、分组及扫描方向，再决定绘图方式。不要自行读取其他对话的附件或把模拟数据当作实验数据。
3. 编写 `.m` 脚本。在任务目录中读取已复制的数据，并将输出保存在同一任务目录或其 `outputs` 子目录。通过 `fileparts(mfilename('fullpath'))` 确定任务位置，避免依赖 MATLAB 当前文件夹或原对话路径。
4. 通过 `bridge_job.py submit --script ... --input ...` 提交独立任务；详细协议见 [references/bridge.md](references/bridge.md)。先写好脚本和全部输入，再原子发布 `request.json`。
5. 通过 `bridge_job.py wait --task-id ... --timeout 30` 等待，并读取该任务的 `result.json`。一次等待最多 60 秒。超时后继续检查原任务，不能把超时等同于失败或自动重复提交。
6. 只有结果为 `completed`、所需输出确实存在且检查通过，才报告成功。检查图形与源数据一致，并实际查看导出的 PNG；必要时检查 FIG 可重开、PDF 可正常显示。

## 绘图约定

- 用户指定的颜色、字体、尺寸、坐标范围、图例和输出格式优先。未指定时采用清晰科研风格，显式设置轴和文字颜色，避免 MATLAB 深色主题影响导出。
- 通常保留 `.m` 和可编辑 `.fig`，导出 300 dpi PNG；需要矢量文件时导出 PDF。保持原始数据不变。
- J–V 数据可能含正反扫描、重复测量、空行和多器件分组。按实际分组绘图，不跨扫描段连线，也不为了消除支线而擅自删点、取绝对值、排序或截断正电压分支。
- 电流 I 转为电流密度 J 需要有效面积和单位；已提供 J 时不要重复归一化。必要信息缺失才提问。
- EQE 应保留波长与百分数/小数单位的含义。若要求积分 Jsc，再确认参考光谱、单位、覆盖范围和缺失区间；普通绘图不自动加入额外计算。
- 不默认平滑、拟合或外推。确有处理要求时保留原始曲线并说明方法。

## 无响应或失败

- 固定目录不可访问时明确说明权限限制，不绕过执行环境权限，也不承诺所有对话都可用。
- MATLAB 未打开时请用户打开；正常配置下无需重新输入桥接命令。若自动加载失效，再查固定目录、`bridge.disabled` 和 `startup.m`；不自动重装或修改启动配置。
- `failed` 时读取该任务的 `error`，修复具体问题后使用新任务 ID。已有 `result.json` 的任务不会重跑，包括遗留的 `running` 状态；不要删除结果来强制重放。
- 本环境曾出现自动启动 `-batch` 的 5201 服务通信错误，以及 COM 的 `0x800401E3`；正常桌面 MATLAB 当时可用。优先沿用已验证的文件桥接，不把这些历史错误当成所有电脑的通用问题。
- 桥接连接的是本机 MATLAB，不是把 ChatGPT 对话嵌入 MATLAB，也不需要 OpenAI API 密钥。

## 用户可以怎样调用

用户只需提供数据和绘图目标，不必重复描述桥接路径。例如：

- `$matlab_draw 用这个 Excel 比较两次测试的 J–V 曲线，区分器件和扫描方向，保存 FIG、PNG、PDF。`
- `$matlab_draw 把图改为白底黑字，调整图例和坐标范围，保留原始曲线。`
- `$matlab_draw 检查 MATLAB 桥接是否在线，先验证连接再绘图。`

只有恢复连接或处理数据确实需要用户操作时，才让用户介入；说明缺少的条件。交付时简要说明数据来源、处理方法、输出和验证结果。
