# 网页获取文章全文与 Supplementary Information

## 定位与下载

1. 将 DOI、题名或本地首页对应到确切文章：题名、作者、年份、期刊/版本。打开 DOI 的出版社落地页，查看真实全文入口和 Supplementary Information / Supporting Information / Supplementary Material / Additional files / Electronic supplementary material 列表。本文参考文献中的链接不是本篇 SI。
2. 默认先获取出版社全文 PDF；已有核验同版本本地全文直接复用，并记录 `reused_local`。PDF 无法获取时，可找出版社开放 HTML、学科公共全文库、机构库或作者公开接受稿；不同版本注明，不能把接受稿或预印本当出版社最终版。Crossref 等用于发现真实链接，不保证所有链接可访问。
3. 全文和 SI 分别尝试：全文收费不代表 SI 也收费，不能因主 PDF 受限就跳过可直接下载的 SI。只使用实际页面/元数据给出的链接，不猜测附件数字或 CDN 文件名。SI 没有独立 DOI 时沿用本篇 DOI 关联，不创建一个虚构 DOI。
4. 使用当前可用浏览器下载或 HTTP 文件下载工具，保存到用户可写目录。浏览器若已获得该出版社访问资格，可沿用已有授权会话；不要导出、打印或复制 cookies/令牌以模拟登录。直链被网站阻挡可转用正常浏览器入口，浏览器工具的使用须遵循该工具支持的 API。
5. 下载全部用于阅读的 SI 文档、补充图表和方法/计算说明。Excel/CSV、Word、图片、ZIP 内附件也记录类型并用可用解析器读取。遇到大型原始数据、视频或只有二进制专有格式时，先核对用途与可读工具，说明需要额外下载/解析的内容及范围；不要默默宣称全部 SI 已读。
6. 验证实际文件：HTTP 成功和 `.pdf` 扩展名不足以证明成功。PDF 应有 PDF 内容签名、能用 PdfReader 打开、有非零页数，检查可见标题/图注对应本篇；HTML 登录/验证码/错误页不能当 PDF。HTML 全文必须实际含完整研究内容；只含摘要的页面不是全文。SI 核对页面来源、说明、题名/作者或版本关联。ZIP 先查看清单，防止解包路径越界，不执行任何附带代码。
7. 保留原下载文件，计算 SHA-256，记录真实来源与获取时间。同一链接/原因失败不无限重试：一般最多尝试两次，再换可用入口或请求必要访问。遵守服务器限流提示，限制在本篇及其相关 SI，避免无关批量抓取。

## 访问受阻时如何请求权限

公开资料的搜索/下载已在用户任务范围内，不先逐个确认网站。只在观察到实际阻碍时提出具体请求，说明哪份全文/SI、网站、已尝试入口和失败原因，并给到实际页面链接。

| 实际原因 | 下一步 |
| --- | --- |
| 执行环境阻止联网或保存文件 | 用相应工具的权限申请，写清下载来源和保存目的；不要把它误称为出版社收费 |
| 出版社/机构登录或订阅页面 | 需要时请求使用用户已有访问资格；让用户在浏览器自行登录/机构验证，完成后继续下载，不索要密码/验证码 |
| 人工验证码或交互确认 | 请用户在真实网页完成该步骤，等待完成再继续，不自动绕过 |
| 401/403/限流/临时网络错误 | 根据页面和响应区分登录、限流或工具不可用；换真实可用入口，不能认为授予本机权限就消除网站限制 |
| 付费且没有现有访问资格 | 查可公开获取的作者/机构版；如仍缺失，提供链接请用户取得文件，不自动购买 |
| SI 未发布、链接损坏或未找到 | 记录 `not_listed` / `not_found` / `download_failed` 及查找范围；权限不能修复不存在的附件，请求用户提供可用文件时不要假装权限可以解决 |

已经得到所需授权则直接继续，不重复询问。等待必须由用户完成的登录/授权期间，可以阅读已取得正文或 SI；需要该授权的下载保持待办，不因等待超时视作同意。用户尚未提供资料时可交付范围明确的部分总结并列缺失，不能标为“全文+全部SI精读完成”。

请求示例（使用实际值替换）：

> 这篇文章的全文下载转到了出版社登录页；SI 已下载。需要你在这个页面完成机构登录，或授权使用已有登录会话。完成后我继续下载并合并阅读。

不把密码、cookies、私密带令牌 URL、机构凭据写进文件、总结或日志。公开原文 PDF 读取优先本地，搜索只发送必要书目标识。

## 获取与阅读清单

在 `bibliography.json` 的 `sources` 列表记录主全文和每份 SI，`prepare` 会保留在 `.match.json`。可另外保存同内容的下载清单；不要求额外修改脚本。示例字段（填实际值）：

```json
{
  "kind": "supplementary",
  "parent_doi": "",
  "label": "Supplementary Information",
  "url": "",
  "local_path": "",
  "sha256": "",
  "format": "pdf",
  "article_version": "version_of_record",
  "retrieved_at": "",
  "acquisition_status": "downloaded",
  "reading_status": "pending",
  "reading_scope": "",
  "failure_reason": ""
}
```

`kind` 可为 `main_fulltext` 或 `supplementary`；获取状态可为 `downloaded`、`reused_local`、`access_required`、`download_failed`、`not_listed`、`not_found`。阅读状态独立为 `pending`、`read`、`partially_read` 或 `unavailable`。失效/登录页不能标 `downloaded`；只在存在实际文件时填写哈希；未验证的格式或版本标为未知。

最终 Markdown 列各 SI 文件、相关方法/图表和实际阅读范围，注明尚待权限/缺失资料。正文证据和 SI 证据使用不同定位，保留重要参数、对照、误差与计算假设；SI 若限制主文结论，应明确指出。

参考：[Crossref 全文链接及访问限制说明](https://www.crossref.org/documentation/retrieve-metadata/text-and-data-mining/)。Crossref 提供元数据和全文链接，实际访问由内容站点决定；DOI 元数据不是全文。
