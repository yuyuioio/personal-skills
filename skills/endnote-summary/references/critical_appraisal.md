# 批判性分析与证据边界

主要主张建立“主张—证据—定位—假设—反例”对应，解释证据缺口怎样影响结论，避免泛列“样本小/需要更多研究”。

- 因果：干预、对照、时序及替代解释是否充分？相关、共现、拟合和示意图不独立证明机制。
- 控制：空白/基准/阳性/阴性对照是否相称？材料变化是否同时改动多个参数？混杂、选择偏倚、批次/漂移能否解释结果？
- 泛化：哪些材料、条件、范围已有证据，哪些推广尚未证明？
- 重现：配方、制备、测试、模型、处理、数据代码是否充分？区分“未提供”和“我未查看”。
- 正反证据：是否讨论矛盾、失败样品和合理反解释？给能区分解释的实验建议。

## 统计和测量

1. 确认独立实验单位，技术重复、多位置、独立批次不是同一种 n；检查伪重复、随机化、盲法、分组与批次。
2. 保留效应方向/大小/变异/CI。显著不等于实际重要，未显著不等于无效应。
3. `±` 是 SD、SE、CI、范围还是扩展不确定度？未定义则未知，不能默认 SD。
4. 保留原单位、面积归一化、量纲和转换依据；转换值不能替代原值或掩盖单位错误。
5. 拟合关注假设、可识别性、区间、残差和不确定性；拟合曲线不是唯一机制证明。
6. 没有原始数据时不制造重分析、p 值、误差传播或新测量结果。

评价先说实际贡献，再解释证据不足、影响和可执行验证。研究本身为依据，不用期刊档次、引用数、影响因子、服务评分或百分制替代证据，不给所有材料/物理论文套临床 GRADE。

正式同行评审另检查目标期刊政策、保密范围和工具许可；普通已发表论文阅读不自动成为保密投稿评审或引入上传审批。对用户研究区分可复现步骤、可比指标、启发假说及尚未证明的推广；每个推断有前提和限制。

提出下一步时把观察、候选假说、机制、预测和证据分开。为可信的替代解释各给区分性预测及可能否定它的观察；支持一个候选不排除未考虑的解释。阅读后提出的假说标为探索性，不能写成作者预先提出或已经证明；短检索没找到不等于具备新颖性。
