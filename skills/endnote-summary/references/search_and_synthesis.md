# 检索、多篇综合和可选连接

## 定向检索

单篇默认先定向查找本篇全文和 SI，获取流程见 [acquisition.md](acquisition.md)。补充其他文献只为关键背景/证据缺口或用户要求的扩展。扩展时明确问题、体系、方法和时间。出版社/Crossref 优先核验 DOI；适用时使用 PubMed/OpenAlex。搜索片段、推荐分、引用次数是发现线索，不是阅读全文证据。

记录查询、来源、日期、筛选、版本和访问范围；按 DOI/题名+作者+年去重，区分预印本、最终版、勘误与撤稿。HTTP 成功但无正文、只有摘要/元数据都明确，不声称全文已读。

按需覆盖近期研究/综述、奠基研究、方法、直接比较、矛盾/阴性结果。不强制所有数据库或固定参考数。用户要求系统综述才建立完整检索式、纳排、筛选流程和适用报告标准；仅几篇 PDF 的整理称文献比较/叙述综述。

## 多篇综合

每篇先生成独立题名+DOI 总结，再作专题比较表：体系、问题、方法、条件、结果、独立重复/不确定度、结论、局限、DOI。按机制/方法/争议组织，不仅串联摘要。量化比较先确认定义、单位、控制与条件可比。矛盾须定位原始来源，不能用综述引文代替未查看实验。引文网络帮助发现路线，引用边不表示因果，PageRank 不表示科学质量。

## 条件性工具

仅当当前会话工具可用且任务需要时调用。文件存在不等于已连接；没有服务继续本地阅读，不自动安装所有客户端、开容器、读取整份 `.env`、保存凭据或上传私人全文。

| 能力来源 | 用途 | 条件/边界 |
| --- | --- | --- |
| paper-lookup / research-lookup | DOI 书目、补充检索、交叉核验 | 实际可用 API/搜索，不强制全通道或深研究 |
| bgpt-paper-search | 全文条件、方法、结果的结构化发现 | 已连接服务；回到原文核验，分数不替代判断 |
| paperclip / paperzilla | 全文定位、行级证据、论文推荐 | 已配置 MCP/服务；检查实际正文/行号，不自动写反馈 |
| exa-search / parallel-web | 学术来源范围的定向搜索/提取 | 已连接授权；原始论文和官方元数据优先，不创建监控 |
| database-lookup | 文中实体/accession 与公开数据核对 | 按学科按需，记 ID/过滤/来源，不当论文结论 |
| open-notebook | 已有笔记库来源问答 | 已有服务/模型；本地推理取决配置，不承诺隐私属性 |
| pyzotero / Zotero | 用户现有 Zotero 库只读全文/条目 | 现有接口，不替换 EndNote、不自动写库 |
| notion-research-documentation | 已授权 Notion 材料比较 | 缓存不等于已安装，默认不创建/发布页面 |
| hugging-science | 科学机器学习论文关联的方法、模型卡和数据集来源 | 目录是线索，不等于论文证据；只核对资源，不自动下载/执行模型代码或调用推理服务 |
| epigraphdb-skill | 公共 GWAS/文献/MR 证据路径查询 | 仅相关学科且接口可用，限定返回规模，保留路径和 ID；关联路径不单独证明因果 |
| folklore-variant-evidence | 公共变异/基因疾病文献与出处 | 仅支持的公开标识，保留 resolved/ambiguous/unavailable 等状态；不提交患者/家庭资料或给临床结论 |

输出统一本地 Markdown。题名与 DOI 供手动匹配，JSON/XML 仅可选只读辅助，不引入自动导入等待。
