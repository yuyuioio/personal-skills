# 单篇阅读、解析和图表

## 必需的总结内容与方法清单

每篇总结明确给出创新点、实现创新的具体方法、实现结果和结论，并以图表/页码建立对应。先盘点正文实验部分、图注、附录和已读 SI 中实际采用的所有表征与测试，按方法去重，保留不同模式/样品/条件对解释的影响。除主要测量外，还需覆盖辅助测试，例如椭偏测厚、轮廓仪、校准测量等；制备步骤不自动算表征，数据解析软件也不自动算独立测试。

在总结最后设置“所有表征与测试方法的原理解析”，每项依次解释“测什么及为何测 → 激励/探测和响应原理 → 原始信号/坐标/单位 → 如何提取目标量 → 本篇用途和图表 → 假设、局限及不能单独证明什么”。需要公式时优先直接插入原文截图，简要解释关键符号、单位和适用条件，不要求手工转写、推导或重新排版；原理背景与本篇实际操作分开，未报告的参数不按常见值补齐。计算/模拟另列模型原理、输入、算法与输出，不冒充实测；仅在参考文献出现或阅读后建议开展的方法不列为本篇已采用的方法。SI 未读时注明清单覆盖范围，不能宣称方法已全部核验。

一般原理可依据稳定的基础知识解释；对不确定、专门或依赖具体实现的原理查官方方法文档或原始方法论文，并引用。来源/附件说明置于原理解析之前，使原理解析成为最后一个内容小节。

## 深度

- 标准（默认）：自动获取正文及 SI，阅读问题、方法、结果和讨论，逐项解释正文全部图表及所有子图，并筛选解释 SI 中支撑主要结论、关键方法/参数、优化、对照和统计的图表。正文/SI 的图题表题、坐标和图内标注均按 [figure_reading.md](figure_reading.md) 解释并嵌入原图。SI 按文件记录范围，缺失或不可读时注明限制及权限待办。
- 快读（用户要求）：首页/摘要、结论、重点方法及关键图，用于筛选；列未读范围。
- 精读/逐图（用户要求）：逐节和逐面板解释正文及自动获取的 SI，讨论原理、计算、替代解释和复现要点，明确未读数据/视频。
- 综述：组织研究路线、分歧与证据强弱；被引实验的数值需追到原始来源才能作为已核验结论。

## 解析选择

1. pypdf 按页提取，检查首页、正文、关键结果页可读性，不能只检查字符总数。
2. 双栏错序/表格列丢失，用已有 pdfplumber 或 LiteParse 布局坐标并对照原页；MarkItDown 是转换，不是总结。
3. 扫描/缺字才 OCR，优先受影响页面，记录语言、工具、页面和数字风险；正常数字 PDF 不先全文 OCR。
4. 图表、结构式、能级图和公式必须渲染/读取关键原页，查看完整面板、坐标、图注、脚注。优先已有 Poppler/PyMuPDF 等工具，不为每篇重复安装解析器。
5. 图像工具不可用时完成可靠部分并明确“图像未核验”及受限结论，不编造趋势或精确像素读值。
6. Word 稿件保留标题、表格、修订状态与图注，必要时渲染；不为 Markdown 总结额外创建 Word/PDF 成品。

易错项：负号、指数、上下标、Greek 字母、光谱单位、面积归一化、归一化曲线与绝对量。多个解析器一致仍不证明公式正确。

## 原文截图与就地插图

1. **先确定来源，再截图。** 对总结要解释的正文或已读 SI 图，从对应的已核验 PDF 物理页渲染并裁切成 PNG，先落盘到本篇总结文件夹的 `figures/`，再写入 Markdown。优先已有 PDF 渲染工具（如 Poppler、PyMuPDF）；直接提取嵌入图片可能漏掉矢量曲线、文字和面板布局，应以页面渲染截图为准。
2. **正确可读即可。** 用宽松选区保留所讲面板/公式及关键坐标、数据、图例和必要尺度，整页也可直接使用。实际查看一次，正确且可读后不再修图；允许留白、邻近文字、页眉页脚及未完整截入的非必要图注，后者读源页并概括即可。仅错图、缺关键内容或影响理解的模糊/遮挡才局部补截一次，仍受限则说明，不循环调 DPI/裁边。不得改变曲线、删除不利数据，或用重绘/AI 图冒充原文截图。
3. **插在相关分析旁。** 在首次实质讨论该图的位置插入图片，紧接来源标注和解释；后续必要时复用同一图片。方法、结果、机制或 SI 小节讲到图时也按此规则，不限于“核心图表怎么读”一节。标准阅读必须讨论并截取正文全部图表，以及选定的重要 SI 图表；共用坐标可集中解释，但每个面板都要有对应解读。SI 未选图表列理由，不用重复整页堆满正文。
4. **使用可搬移的相对路径。** 主总结与 `figures/` 保持同一父文件夹，图片名区分正文、SI 文件和页/图/子图，例如 `main_p05_fig03.png`、`si1_p06_figS04a.png`。Markdown 写 `![正文 Fig. 3：堆积结构](figures/main_p05_fig03.png)`，路径使用 `/`，文件名尽量不含空格或特殊字符；不写 `Z:/...`、`C:/...` 等盘符绝对路径或临时目录链接。以最终主 `.md` 所在目录解析路径，不能依赖当前工作目录或草稿位置。
5. **图旁解释证据链。** 说明为什么做该测试，轴/单位/图例如何读，观察到的数值或趋势意味着什么，以及据此支持的结论和不能单独证明的内容。截图下标注“正文 PDF 物理 p. X / Fig. Y”或“SI 文件名，物理 p. X / Fig. Sx”，避免混淆正文/SI及印刷页码。
6. **一次检查成品与资源。** 打包后用结构检查确认最终主 Markdown 的图片链接和文件存在；对应内容与可读性复用首次实际看图记录，不重复打开已确认截图。移动/复制文章文件夹时连同 `figures/` 一起保留；只移动 `.md` 会破坏图片关系。能用本地 Markdown 阅读器预览时检查显示，未实际预览不能声称已在 MarkText 验证。PDF 受限、损坏或渲染工具不可用时，说明缺失的图、原因和受限结论，继续可靠部分，不留下伪造截图或无效图片占位。

以下仅示范排版，实际交付前必须替换为真实截图、定位和分析：

```markdown
![正文 Fig. 3：堆积结构](figures/main_p05_fig03.png)

来源：正文 PDF 物理 p. 5 / Fig. 3a–c。

- 为什么测：检验处理是否改变分子堆积。
- 数据怎么看：先区分峰位、径向峰宽与角向分布，再比较同条件数据。
- 数据说明什么：写本图实际观测及换算得到的物理含义。
- 支持什么结论：说明所支持的机制步骤，以及还需其他证据验证的部分。
```

## 正文与 SI 联读

先查看每份 SI 的目录/内容范围，建立与正文方法、图表、结论的映射。读制备/表征条件、控制、器件/样本重复、拟合/计算细节及补充图表，把关键条件和限制合并进主总结。SI 下载成功只代表文件可得，不能自动标已读；已阅读文件也不意味着逐项分析所有原始数据。分别引用正文物理页码与 SI 文件名/页码/图表号，不能把 Fig. S1 写成正文 Fig. 1。

## 图表解读顺序

执行 [figure_reading.md](figure_reading.md) 的覆盖清单与逐图/逐表结构：正文全部图表、SI 选定图表的所有面板逐一回答图题/表题是什么意思、测什么及为何测、坐标/单位/尺度与图内标注、条件可比性、直接观察、作者解释、替代解释、对应哪项结论，以及该测试的响应原理为什么能检验该结论。共享坐标可只定义一次，不能因此省略任一子图的结果和结论。

- 表格检查单位、脚注、最佳值标记、缺失项及比较基准。
- 机制图解释对象位置、状态、箭头与能量/电荷流向；示意图不等于实验证明。
- 动力学分清物种归属与拟合推断，寿命不自动等于单一通道速率，速率方程列假设。
- 性能比较需同条件；归一化曲线不能比较绝对产率。
- 低分辨率图不能猜精确值；数字化确需进行时说明方法与估读误差。
- 检查零基线/截轴、对数变换、双纵轴、面板归一化、平滑及色标范围是否改变直观比较；缺失数据不当零值，热图颜色不直接等于物理量，图像必须有比例尺和处理说明。

首次术语保留原缩写和文章具体含义，歧义缩写不凭通用知识展开。分清作者报告、作者提出及代理推断。主 `.md` 的相关分析必须配原文截图和文字解释，截图按上节用相对路径就地插入；文件夹与图片共同构成可阅读的交付包。表格仅转写关键对照值，清晰原表不再整表抄写；公式用源页截图和简短变量说明，共享原理集中解释、交叉引用，不重复转写同一公式；可选 Mermaid 只在帮助理解时使用；原文截图不是新绘图任务，不要求另外绘制机制图或生成幻灯片。
