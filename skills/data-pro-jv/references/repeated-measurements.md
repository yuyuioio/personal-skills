# 重复测试比较与异常标注

适用于同一样品的两组及以上独立测量。组指一次测量文件/扫描批次，文件内CH1、CH2等是测试点；Excel结果分组另以样品计数。

## 配对与比较口径

- 先按样品编号确认归属，再按通道或用户明确的测试点对应关系配对，并核对原始Name、面积与测量条件。不同样品即使Name相同也不能比较。文件名后缀表示测量次数须有当前请求依据，不能盲目把后缀当样品或重复次数。
- 使用仪器报告PCE及未四舍五入的数值，默认相近阈值为相对差≤5%，不是5个百分点。四项参数的高值前缀筛选不影响本节重复性比较。
- 对非负PCE定义 `d(a,b)=|a-b|/min(a,b)`。正值按此式计算；两个零记为0；仅一个零则相对差无定义，标为“单组为零”并按不相近处理，不伪造无穷百分比。负PCE、缺失或非有限值另标“比较值无效/缺失”，保留原值与来源，不补零、不当成已通过。
- 去重后计数。被多个文件重复引用的同一完整测试只投一票，不能让重复导出形成虚假多数。保留独立测量的时间、组号、通道与所有重复来源。
- 缺点、通道不一致、面积或已知测量条件不同的组不能作为直接可比重复测量。明确缺口或按条件分开比较，保留全部供判断，不靠组均值掩盖无法配对。

## 两组数据

1. 列出所有对应点的两次PCE、绝对差（百分点）、相对差及≤5%判定。
2. 所有点均有效、完整配对且≤5%时，比较两组所有配对点的算术平均PCE（包括真实零值），保留平均PCE较高的完整一组。均值相同保留两组。
3. 任一点超限、无定义或不可比较，则两组均保留，列出触发点。不逐点各取最大值，不因为大部分点相近就只保留一组。
4. 两组无法凭多数判断哪次异常，只标“两组差异超限/需判断”，不武断把较高或较低组称为异常。

## 三组及以上：多数相近，少数偏离

先对同一样品每个测试点独立判断，再合并为组级提示。PCE是主要判据，Voc、Jsc、FF、Rs、Rsh和曲线可提供附加观察；不直接把指标单位混合，也不据此自动推断异常原因。

默认采用以下保守、可复核的判据。5%沿用两组比较口径，是工作流阈值，不是统计显著性检验。用户提供其他阈值或实验精度时按新口径，并在表内说明。

1. 设该点有N次独立且可比的测量，须N≥3且所有待比组在此点均有有效PCE，才能作完整多数判断。缺失/无效组另列，不用少量剩余值冒充完整多数。
2. 对有效PCE从小到大排序，找任意两成员均满足 `d≤5%` 的最大成员集合。正值等价于最大值/最小值≤1.05；零值仅与零值相近。不得用相邻值链式连接，将首尾相差较大的测量纳入同一相近群。
3. 只有成员数**严格超过N/2**、且最大集合的成员构成**唯一**时，认定为“多数相近群”。最大集合并列（即使相互重叠）、两个等大群、或最大群不超过半数，都标“无法确定多数相近群”，所有组保留。
4. 参考值是多数相近群PCE的中位数。群外测量与参考值的相对差>5%时标“疑似异常（偏高）”或“疑似异常（偏低）”。参考/测量仅一方为零则标“疑似异常（单组为零）”。列出参考中位数、多数成员及票数、该组PCE、偏差、方向和触发点。群外但未明显偏离参考的值标“群外边界值/需判断”，不强称异常。
5. 一个组只要有一个点疑似异常，就增加组级“含疑似异常点”提示，并列出点名；不能因此宣称整组所有点均异常。高于多数的少数极大值同样可能异常，不能因PCE高就直接推荐或择组。
6. 首先筛出并保留疑似异常组供用户判断。可另列“多数相近候选组”。只有至少两组候选完整、各点多数基准明确、候选组所有对应点两两相近，且无边界/缺失待判断项时，才在候选组中按全点平均PCE择出一整组作为“建议保留”；并列均值全部保留。否则保留所有候选组并说明，不自动从混合群中拼接一组。
7. 疑似异常、边界值、无法确定多数的组始终保留。它们不能被自动删除或仅存在于临时JSON，也不能作为其他样品的多数比较基准。用户可根据异常筛选表自行决定最终采用与否。

说明性算例：某点3次PCE为10、10.2、6，前两次相近且构成2/3多数，6相对参考中位数10.1明显偏低；10、10.2、14同样把14标为偏高疑似异常。仅10和6不能判断哪次异常。4次10、10.1、6、6.1形成2对2，不能指定多数。

## Excel呈现与保留

- 组均值及其他派生数值同样使用Excel单元格公式，引用该组原始PCE与对应记录；保留平均值计算、差值和相对差的核对路径，不将脚本预计算结果写成不可追溯的统计常数。无效/零值按本文件口径显式处理，不用IFERROR补零掩盖问题。建议择组和异常判断仍需按本次完整比较重新核验。
- **全部参数**保留所有当前输入的去重原始测试，包括疑似异常和未被建议采用的组。增加“样品编号”“测量组/次数”“保留状态”“异常标记”“异常依据”，参数名称横向作列、每条测试占一行，原始名称在首列、CSV来源在末列，PCE子表也采用此方向。
- **重复测试对比**显示逐点PCE、相对差、比较基准与组级判断；上方列各组全点平均PCE、建议保留组及触发点。两组与多组采用各自判据，注明阈值和零值口径。
- **保留结果**列按上述规则建议采用或需人工判断的完整组及全部参数。两组全点达标时仅此表择高；未选组在全部参数与原始扫描中仍可追溯。保留状态区分“建议保留”“两组均保留”“候选组均保留”“疑似异常保留待判断”“无法确定多数/全部保留”，不暗示用户已批准排除。
- **异常筛选**单列疑似异常点及其涉及的测量组，含报告PCE、多数中位数、相对偏差/零值状态、方向、多数成员及票数、触发点、完整来源和空白的“人工判断”列。没有疑似异常时明确记录0，不能把差异超限或缺失自动计作多数异常。
- **全部原始扫描**保存所有输入去重测试的完整实测V/I/J、测量时间、样品、测量组、点名、源CSV行号，不限FF或PCE达标者。原始参数与测量符号不改写。
- 疑似异常的相应PCE/异常标记单元格用浅红底、深红字；无法确定多数/边界/缺失用浅橙底及文字原因。不能仅靠颜色表达，也不能整行覆盖交替底色。黄色优选指标、绿色优选文字照常使用；疑似异常的高PCE同时保留异常提示。
- Jsc筛选、Voc筛选、PCE筛选、FF筛选各自基于全部去重记录执行高值前缀与相对均方根偏差<5%规则，保留全部并列最佳值；保留状态与异常标签随记录显示。不再生成PCE曲线或J–V图，分布点图绘入选原值，横向仅防重叠，不按数值排名；另标均值和总体标准差。原始数据不因建议择组隐藏。
- 默认每4个样品一个Excel，同一样品全部次数不能拆分；不同样品间的空白分隔行从该表第一列到最后一列填充深蓝色#183153，默认行高约8磅且不写数据。同一样品不同次数之间不加分隔行。适用于含样品分隔行的全部参数、FF筛选、保留结果、异常筛选及汇总等表，说明区留白不着色。所有参数表继续用深蓝空白分隔行；扫描数据每组V/I/J三列及CSV行号，组内点向下、不同组横向并排且顶端对齐，紧凑列宽与行高，仅留窄空列；不将各组上下堆叠，也不把扫描点铺成一行。同次产生多个Excel时另建含四项筛选、全部参数、全部原始扫描的汇总，重新执行四项筛选并保留四张参数分布点图；保留状态、异常标记、异常依据及所属结果组随原始记录汇总，不画J–V曲线、不重复投票。

## 核验

核对源文件清单、每个样品次数与点数、点名/条件匹配、去重来源及有效票数、≤5%边界、均值与中位数、最大相近集合及唯一性、异常方向、缺失/零值、各组保留理由。所有原始记录必须能在全部参数和全部原始扫描定位，建议择组及疑似异常筛选不得丢失来源。报告原始记录数、完全重复数、建议保留组数、待判断组数、疑似异常点数及涉及的不同组数，不把点数当组数。
