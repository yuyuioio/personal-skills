# 重复测试逐点择优

适用于同一样品同一点的多次测试。替代旧版整组择优和多数相近群规则。处理顺序：完整测试去重 → 同样品同点择优 → 四项独立高值前缀筛选 → 逐列平均。

## 样品和测试点

- `样品-1.csv`、`样品-2.csv`共享样品主体；末尾相同字母导出标签保留，如`A34-1-O.csv`与`A34-2-O.csv`归为`A34-O`，不同标签不自动合并。无编号的同主体文件也可参加。默认只在同目录内配对；用户确认跨目录同样品时显式填sampleId。明确的sampleId、measurementGroup和pointId优先。
- 点位优先按pointId，其次按原始Name中的CH号配对（CH1与CH01为同一通道），无CH号时用完整Name。Name中的测量次数字样不改变CH归属。缺少通道时不能使用横向组号配对，因为缺点/重排会使组号漂移；无明确点名的记录各自保留并标识未确认。
- 缺点时独立处理实际存在的点，不要求整组点数相同。不同样品的同名通道不合并。不同面积、明确不同测量条件或扫描方向分开比较；输入有其他已知条件时应填写conditionKey/conditionId/conditionLabel，不能仅因文件主体相同混算。
- 相同完整测试先去重，重复导出不增加候选数。原始记录ID及全部重复来源始终保留。

## 确定性择优

1. 每个样品/点位/条件独立找有限PCE中的最高值M。
2. 对各次PCE值x定义`d=|M−x|/min(M,x)`。正值按未舍入十进制计算。仅当`d<0.05`时进入FF比较。恰好5%不进入，差异是相对值，不是5个百分点。
3. 在上述候选中保留FF最高的完整记录；FF相同取PCE较高者；PCE与FF仍相同按输入顺序取首条。最高PCE总是候选。三组及以上直接与M比较，不能依次两两淘汰，也不能用链式接近扩大候选。
4. 相同零PCE相对差定义为0，可比较FF；仅一个值为零或涉及不相同负值时相对差无定义，该记录不进入近优FF比较，仍可按最高报告PCE选中，显示原因。不得补零、改符号或伪造百分比。
5. 重复记录PCE缺失/非有限时不参加择优；若全部缺失则没有自动胜出者，保留原始数据并提示无法择优。近优候选FF缺失时优先在有效FF中比较；若均无有效FF则按PCE选取，并注明比较不完整。唯一测试记录保持可用，其某项参数缺失只影响该项后续筛选。
6. 选中的是整条实测记录，包含同一来源的Voc/Jsc/PCE/FF及其他参数和完整扫描。不同测试点可选自不同组；不得把同一点不同记录的参数拼在一起。

示例：同点PCE/FF为10.0/60和9.8/65，差约2.04%，选9.8/65；10.5/60和10.0/65恰差5%，选10.5/60。三组10.0/60、9.6/65、9.2/80仅前两组进入FF比较，选9.6/65，不让9.2通过链式接近入选。

## Excel与统计

- 全部参数、全部原始扫描保存所有去重原始记录。增加样品、测量次数、测试点、保留状态、胜出记录和择优依据；“未选用”不代表异常或已删除。
- 有重复点时增加“重复测试对比”，按记录显示PCE、FF、同点最高PCE、与最高PCE的相对差、选用状态和理由。最高PCE和相对差用单元格公式引用本表对应点的原值，缺失/无定义显式显示无法计算。
- “保留结果”只列逐点胜出的完整记录以及不重复的点。Jsc/Voc/PCE/FF四表从该范围分别做既有严格相对均方根偏差<5%的高值前缀筛选，不能各自从同点其他测量取更高参数。重复PCE的5%与筛选离散度的5%是不同步骤。
- 每个筛选表的入选区最后一行，用Excel公式对全部物理参数逐列计算均值；仅计本表入选行，不平均记录ID、测量序号、时间、来源或偏差辅助列。保留结果底部也计算同口径均值。PCE均值直接平均逐条原始PCE。
- 修改已有原值后平均值、比较数字和图表引用重算；选用状态和筛选成员是本次算法结果，必须重新运行才能重选。不得声称Excel会自动完成逐点重选。
- 既有排版、分布点图、完整扫描横向分块和测试日期归档规则不变，不绘制J–V曲线。
- 汇总重新从本次全部去重原始记录逐点择优，再做四项筛选和平均；不拼各组均值，也不只合并各组已选记录而丢掉候选。

## 核验

验证同名不同样品、编号文件、CH缺点/重排、两组与多组、PCE严格5%边界、PCE/FF并列、输入次序稳定性、真实零/缺失和明确不同条件。核对每个可比较点仅一条胜出记录且全部参数来自同一ID，未选记录与扫描完整可追溯。逐列核对平均值公式范围和数值缓存，在临时副本修改一个入选参数验证其均值更新且不影响其他参数。报告去重数、择优候选数、重复点数及无法择优情况。
