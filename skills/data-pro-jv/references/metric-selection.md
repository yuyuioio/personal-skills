# 四项参数筛选

用户确认的阈值是相对均方根偏差严格小于5%，即总体标准差除以均值绝对值，也称总体CV；不是原始MSE除以均值，也不是归一化MSE小于0.05。公式使用n，底层按未舍入值比较。

## 候选与算法

1. 先按[重复测试逐点择优](repeated-measurements.md)选择同一样品同一点的一条完整记录，只取当前工作簿范围内逐点择优后保留的测试。原始去重记录全部保留供追溯。分别对Jsc、Voc、PCE、FF取有限数值；缺失/非数值不补零，记为该项无效，其余指标仍可使用。真实零、负数不静默删除。使用报告原符号，最佳为报告最大值。
2. 每项按值降序、并列按输入顺序排序。只考察完整同值组结尾的前缀，保证所有并列最佳及边界同值不被任意拆开。
3. 对每个前缀算 `μ=Σx/n`、`MSE=Σ(x−μ)²/n`。μ为0则相对量无定义；否则检验 `MSE / μ² < 0.05²`，与开根号后的相对量<5%等价。建议用Decimal从原数值的十进制表示计算，避免浮点使恰好5%误过。
4. 遍历全部前缀后，取通过的最长一个，不在第一次失败时停。输出原始记录身份、原始精度值、均值、原始MSE、相对均方根偏差、候选数、有效数、入选数、未入选记录及原因。
5. 无有效数值时入选0、统计不可用。若没有任何前缀可定义并通过（如全部为0），仍保留最佳同值组以展示原始值，标记“未达标：均值为0，相对偏差无法计算”，不宣称通过。仅1点时相对量虽0，写“仅1点，无法评价离散性”。

脚本为每项生成独立的selectedIds，不能把PCE的入选集合套到其他指标。已知不同实验条件按当前分组分别分析。四项高值选择可能使均值偏高，应在每表写“高值优先筛选后的均值”；它不是全批平均、测量精度、重复性结论或异常剔除证据。筛选时的降序不用于展示：表与图恢复原始输入/测量顺序。

## Excel布局与分布图

- 四项子表及全部参数、未入选数据均为**一条测试一行、参数名称横向作列**，PCE无例外；原始测量序号作列，序号值随记录逐行向下。首列保留文件名/点名，末列保留CSV来源。
- 所有统计结果用单元格公式：均值用AVERAGE，逐点偏差=x−均值，偏差平方=偏差^2，原始MSE=偏差平方之和/COUNT(入选原值)，总体标准差=SQRT(MSE)，相对偏差=总体标准差/ABS(均值)。无有效值或均值为0时显式显示无法计算，不补零。均值/标准差绘图数据同样用公式链接；导出后核对公式、缓存，并通过临时改值验证重算。
- 第2行为指标标题，第4～8行显示公式计算的均值、原始MSE、总体标准差、相对均方根偏差、n、范围、状态及σ定义；第10～25行是分布图；第28行起是入选原始数据表。入选表最后一行是全部物理参数的平均值，各列用COUNT和AVERAGE公式仅引用本表入选原始行，不包含自身、未入选数据或辅助区；编号、时间、偏差列不平均。真实零和负数参加平均，空白忽略，无有效值显示无法计算。未入选/无效记录另区纵向列出来源与原因，包括重复测试择优未选用记录。
- 分布点图的每个蓝点取一条入选原值作Y；X用与数值无关的确定性小幅错位，避免同值覆盖。保持原始输入顺序，不画降序排名图，不连接原始点。
- 绿线为均值，橙色误差棒两端为μ±总体σ；σ=sqrt(MSE)，分母为n，不是n−1。n=1不画σ；σ=0保留真实同值点，不人为增加纵向噪声。明确横向位置仅防重叠、误差棒是总体标准差。
- 所有图表系列绑定可核对的纵向辅助数据。蓝点原值用公式链接下方记录，均值线与标准差系列独立，不能把它们当成实测点计入n。原始MSE和单位仍可在辅助数据/报告中核对。
- 所有J–V扫描数据每组用V/I/J三列、CSV行号另列；组内点逐行向下、组与组从左到右并排，统一表头和首点行，组间只留约2字符宽的空列。仅原始扫描表按实际显示值收紧列宽和行高，不能将各组上下堆叠。不把长扫描点横向展开，也不恢复J–V绘图。
- 真实零、缺失、n=1、严格5%边界处理不变；FF/PCE原值与相对偏差的百分比格式分开。

## 核验算例

- `[105,95]`的均值100，MSE25，相对量恰好5%；不能同时入选，应只保留105并标仅1点。
- `[100,100,99,20]`需包含两条独立最佳100，选择前3条，原始20仍可追溯。
- `[10,10,10]`全部保留；`[0,0]`相对量不可用，不能标0%达标。
- `[10,1]`只留10，明确仅1点；不删最高10来选低值簇。
