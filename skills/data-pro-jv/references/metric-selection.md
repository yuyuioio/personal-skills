# 四项参数筛选（2.5版）

用户确认“偏差”是总体标准差除以均值绝对值，即 `CV=√[Σ(x−μ)²/n]/|μ|`。分母n，不用n−1，不是逐点相对偏差。所有新边界均包含等号，按未舍入十进制数值判断。

| 指标 | CV上限 | 额外要求 |
| --- | --- | --- |
| Jsc | ≤0.8% | 保留全部并列候选最大值 |
| Voc | ≤0.8% | 保留全部并列候选最大值 |
| FF | ≤1.3% | 保留全部并列候选最大值 |
| PCE | ≤1.2% | 每条入选PCE距本条件候选最大PCE≤2.5个百分点，并保留全部并列最大值 |

旧“四项统一严格<5%”已取消。同样品同点重复测试中PCE相对差严格<5%时比较FF的择优步骤未改变，不能把两个步骤的标准混用。

## 候选与算法

1. 完整测试去重，再按[重复测试逐点择优](repeated-measurements.md)保留同一样品同一点的一条完整记录。同一明确实验条件的择优记录组成候选，不跨条件混算。其他原始记录完整保留。
2. 每项独立取本项有限报告数值，不补零、不翻转符号、不先用另一指标裁候选。按自身值降序，并列按输入顺序；只考察完整同值组结尾的前缀，不拆并列最佳或其他同值组。
3. 对每个前缀，用Decimal计算均值μ和总体MSE。μ非零时检验 `MSE/μ² ≤ threshold²`，Jsc/Voc threshold=0.008，FF=0.013，PCE=0.012。避免显示舍入或浮点误判等号。
4. PCE还须满足 `max(PCE候选)−min(PCE本前缀)≤2.5`，相当于每条入选值都距候选最大值≤2.5个百分点。最大值在全部本条件择优候选上确定，不在裁剪后重设，也不用入选均值替代。
5. 遍历全部有效前缀后选同时满足全部标准的最长前缀，不在首次失败时停止。各项并列最大值全部入选。降序只用于选集合，表和点图恢复原输入顺序。此规则是高值优先，不声称为任意子集最大样本量或无偏估计。
6. 无有效值时入选0；均值为0时CV未定义，不能报0%通过。无达标前缀时保留最佳同值组作展示并标未达标。仅1点时CV虽为0，仍明确“仅1点，无法评价离散性”。真实零/负值和所有未入选值及原因保留。

## 表格、公式及首页双总结

- 所有参数表前12列固定为：编号、Jsc (mA/cm²)、Voc (V)、FF (%)、PCE (%)、Pmax (mW)、Imax (mA)、Vmax (V)、Rs (Ω)、Rsh (Ω)、Isc (mA)、日期。面积、记录ID、偏差、状态和来源等在日期之后，来源在最后。原始V/I/J扫描及绘图辅助区保留各自布局。
- 原值直接来自主参数列，不为旧公式示例增加靠前的目标值副本。均值用AVERAGE，偏差=x−μ，偏差平方=偏差²，MSE=SUM(偏差平方)/COUNT(目标入选值)，σ=SQRT(MSE)，CV=σ/ABS(μ)。均值为0/无有效值显式无法计算。PCE候选最大值MAX及逐点绝对差也用公式。
- 入选区底部紧接全部物理参数平均行，每列独立COUNT/AVERAGE，仅引用本表入选原值；不含自身、未入选区或辅助区。真实0/负数参加平均，空白忽略。编号、日期、记录ID及偏差不平均。
- 顶部显示均值、CV、n及本指标标准，状态公式按各项新上限包含等号判断；PCE同时检查2.5个百分点。修改原值后统计、状态和图表参考值重算，但不会自动重选成员。
- 首张“总结”表放两份按条件分行的总结。第一份四项分别引用各自筛选均值与n/CV，其余物理参数留空解释不同集合；第二份所有物理参数均引用同一PCE入选集合的逐列平均值。两份总结的前12列相同，n/CV等在日期之后。详情见SKILL.md“首页双总结”。
- 四张指标表保留分布点图、均值与±1总体σ，不连蓝点，不按数值排名。n=1不画σ。图下列入选原值，其后为平均行及未入选区；X仅确定性防重叠。原始扫描仍横向并排、V/I/J/CSV行号向下，不画J–V曲线。
- 导出后核对统计/平均/首页链接/逐点偏差公式文本及缓存，在临时副本改值验证统计、首页与绘图引用更新；核对最大值未丢失、各条件独立及全部未入选来源。

## 核验算例

- Jsc/Voc `[100.8,99.2]` 的μ=100、CV=0.8%，两条都通过；把99.2改为99.199则超出边界。
- FF `[101.3,98.7]` 的CV=1.3%，数学筛选包含等号；101.3%应另标超出物理范围，不能为凑阈值静默删除最高值。
- PCE `[101.2,98.8]` 的CV=1.2%、绝对差2.4个百分点，两项边界均通过。另测 `[200,197.5]` 恰差2.5且CV达标，两条保留；`[200,197.499]` CV仍达标但距最大值超2.5，只保留200并标单点。大数算例仅验证数学边界，不代表有效器件。
- `[10,10,10]` 全保留；`[0,0]` CV无法计算；`[10,1]` 保留10并标单点；同值独立记录全部计数，重复导出只计一次。
