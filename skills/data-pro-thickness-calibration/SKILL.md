# data-pro-thickness-calibration

把每种膜材料的镀膜仪原始显示厚度、椭偏仪测试厚度，以及二者差距整理成可追溯、可重新计算的表格。默认使用中文、厚度单位 nm，优先交付 Excel 文件，并在回复中给出简短结果表。

## 输入与分组

- 原始镀膜仪数据：用户给定或原始记录中的显示/设定厚度。两者若不同，应单独保留并明确用哪个作比较基准；本会话使用用户报告的镀膜仪显示厚度。
- 测试标准数据：本任务中指椭偏仪的测试厚度，作为本次比较参考，保留测试来源。不要宣称椭偏读数是无误差的真值。
- 用户的新批次参数优先；不得沿用上批次的材料厚度。未知值留空，不用 0 代替，不根据实测均值猜测。
- 按批次和材料/样品组分别统计。D1、D2 等独立组保留原标签；同材料不同设定厚度不能直接混合统计。图片顺序不等于测量序号，使用文件名或截图 Data 字段定位。
- 核对各组测量数量，保留所有有效原始读数。除非用户指定或有明确证据，不因某个读数不同或 MSE 较大而自动删除。

## 提取测量值

1. 表格若已有数值，读取数值及对应样品标签；Excel 若嵌入截图，提取嵌入图片或直接查看图片。
2. CompleteEASE 截图读取左侧 Fit 区的 `Thickness #… = 数值 ± 数值 nm`。C70、D、MoO3 的膜层可能是 Thickness #2；不要把基底上固定的 1.50 nm 氧化层 Thickness #1 当作目标膜厚。以目标膜材料对应的拟合层为准。
3. 分别记录 Thickness、软件报告的 ± 值、拟合 MSE（后两者可选）。截图中的 ± 值与多次测量的样本标准差不同，不能混写。
4. OCR 只能辅助。核对原图中的小数点、数字、单位、层号和样品标签；不清楚的读数注明待确认，先处理不受影响的数据。
5. 若源文件被 Excel 锁定，先尝试以共享读取方式建立临时副本，或者读取已授权的活动工作簿。无需为了新建结果表强制关闭源文件。

## 计算口径

对同一组有效厚度读数 x₁…xₙ，镀膜仪显示厚度 I：

| 指标 | 定义 |
|---|---|
| 平均实测厚度 | x̄ = Σxᵢ/n |
| 样本标准差 SD | sqrt[Σ(xᵢ−x̄)²/(n−1)]；n 小于 2 时留空 |
| 变异系数 CV | SD/x̄ ×100% |
| 厚度差 | Δ = x̄−I，单位 nm，保留正负号 |
| 相对偏差 | Δ/I ×100%；正值表示实测膜更厚，负值表示更薄 |
| 实测/显示比例 | x̄/I，注明为倍数 |

逐条测量也可计算 xᵢ−I 和 (xᵢ−I)/I。Excel 百分比单元格应存小数比例，再用百分比格式显示，避免重复乘以 100。

厚度差默认是有方向的差。若用户要求绝对偏差幅度，再增加 |Δ|，不要用它替代有符号的厚度差。未知 I 时，均值与 SD 仍计算，厚度差、相对偏差和比例留空；I=0 时不能计算比值，标记待确认。

本会话的偏差分母是镀膜仪显示厚度。若用户要求以椭偏参考值为分母的“仪器示值误差”，另算 (I−x̄)/x̄ 并清楚标注，不与上述相对偏差混用。材料间偏差分别报告，不把不同材料的结果直接平均成一个通用校准系数。

## 输出工作簿

使用当前环境可用的表格工具；若有适用的 spreadsheet skill，按其要求创建和验证工作簿。本 skill 的统计脚本仅依赖 Python 标准库，不绑定某款 AI 或表格插件。

默认两张工作表：

- **原始测量数据**：批次/材料组、样品编号、测试厚度 nm、软件报告 ± 值 nm（有则保留）、MSE（有则保留）、镀膜仪显示厚度 nm、厚度差 nm、相对偏差、源文件名或工作表/图片定位。
- **厚度测试结果**：批次/材料组、读数数 n、显示厚度 nm、实测均值 nm、样本 SD nm、CV、厚度差 nm、相对偏差、实测/显示比例、比较结果。

原始数据保留截图精度，统计时使用未提前取整的数据。均值和 SD 默认显示 3 位小数、百分比 2 位小数；按源数据精度或用户要求调整。页下注明公式、偏差方向、测试来源，明确“均值 ± SD”中的 SD 是组内测量离散性。

显示厚度输入格与公式格采用不同底色。均值、SD、差值与比值尽量使用 Excel 公式，原始记录可追溯；未知显示厚度的输入格真正留空，公式用空值判断返回空白，填入显示厚度后自动计算。示例：`=IF(C6="","",D6-C6)`；比值还应判断显示厚度不为 0。单次测量用 n 判断防止 `STDEV.S` 报错。

按用户指定名称输出，例如 `307.xlsx`。不覆盖源文件。最终输出的所有 Excel 表格统一保存到下述测试日期文件夹，并提供各表格的文件链接；回复只需简短列出各组“均值 ± 样本 SD”和相对偏差。

### 按测试日期建立结果文件夹

- 在 `Z:\user\desktop\Data\SE\1result` 下创建以实际测试日期命名的子文件夹，文件夹名格式为 `YYYYMMDD`。例如测试日期为 2026 年 10 月 15 日，结果文件夹为 `Z:\user\desktop\Data\SE\1result\20261015`；该文件夹已存在时使用已有文件夹。
- 将本次最终输出的所有 Excel 表格保存到对应的测试日期文件夹中，包括分组结果表和汇总表（如有）。保留各表格原本的文件名或用户指定的文件名，例如 `20261015\307.xlsx`；日期用于文件夹命名，不强制用于表格文件命名。该日期文件夹是最终表格的统一保存位置，不再按日期文件名向 `1result` 根目录另存副本。
- 测试日期优先采用用户明确给出的日期，其次采用原始测试记录中可核实的测试日期；不能用生成日期、当前日期或文件修改日期代替。日期缺失或互相冲突时，先完成不依赖日期的数据处理，再确认日期后保存最终表格。不同测试日期的结果分别保存到对应日期文件夹。
- 结果日期文件夹中只保存最终 Excel 表格文件；JSON、脚本、截图、预览、日志及其他中间文件均保存在工作目录或临时目录，不写入结果日期文件夹或 `1result` 根目录。
- 保存后核对本次最终表格清单，确认所有表格均位于对应日期文件夹且能够读取。已有同名文件且内容相同时无需重复写入；内容不同时先确认是否覆盖，避免丢失已有测试结果。回复中提供实际保存位置和各表格链接；保存失败时明确说明实际保存状态。

## 检查与复用脚本

核对源文件数量、组名、样品编号和读数数量；用独立计算检查均值、SD、偏差方向和分母，检查公式错误。未知显示厚度的差值应为空；若具备公式计算能力，临时填入值验证自动计算，再恢复空白后保存。查看表格预览，确认表头、单位与数据没有截断。

需要可重复统计时，运行 [scripts/calibrate.py](scripts/calibrate.py)：

```text
python /实际skill目录/scripts/calibrate.py measurements.json --output statistics.json
```

输入为组列表或 `{"groups": [...]}`，每组结构如下；`instrument_nm` 可省略或设为 null。将用户的新输入标准化为此格式，不要要求用户手写 JSON：

```json
[
  {
    "material": "D",
    "batch": "307",
    "instrument_nm": 10,
    "readings": [
      {"sample": "D-1", "measured_nm": 6.45, "fit_error_nm": 0.006, "mse": 1.518, "source": "D-1.PNG"},
      {"sample": "D-2", "measured_nm": 6.60, "source": "D-2.PNG"}
    ]
  }
]
```

脚本输出统计值与逐条测量的差值，缺失结果为 null；输出的 `relative_bias`、`cv` 是小数比例，`measured_to_instrument` 是倍数。该 JSON 用于交叉验证或导入表格，最终仍按用户要求输出 Excel。

本会话的 307 批次可作回归核对，不能作为后续批次默认参数：D 的 I=10、均值 6.436、SD 约 0.100、偏差 −35.64%；C70 的 I=40、均值 32.912、SD 约 0.178、偏差 −17.72%；BCP 的 I=4.7、均值 5.334、SD 约 0.071、偏差 +13.49%；MoO3 的 I 未知、均值 10.142、SD 约 0.158、比较列留空。各组 n=5。
